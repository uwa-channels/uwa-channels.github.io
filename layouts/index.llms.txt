## Paper and data

- [Underwater Acoustic Channel Library](https://arxiv.org/abs/2609.03207): The paper describing the library, arXiv:2609.03207.  Cite it if you use the channels, the noise models, or the code.
- [Underwater Acoustic Channel Repository](https://doi.org/10.5281/zenodo.21287414): The channel impulse responses and noise statistics on Zenodo, version 1.0, CC BY 4.0.  [doi:10.5281/zenodo.21287413](https://doi.org/10.5281/zenodo.21287413) always resolves to the newest version.

## Code

- [MATLAB toolbox](https://github.com/uwa-channels/matlab): `replay`, `noisegen`, and `unpack`; files load with the built-in `load`.  Install the add-on with `matlab.addons.install(websave([tempname '.mltbx'], 'https://github.com/uwa-channels/matlab/releases/latest/download/uwa-channels.mltbx'))`.  MIT license.
- [Python package](https://github.com/uwa-channels/python): the same functions, plus `load_channel` and `load_noise`, which read `-v7.3` and MAT v5 files.  Install with `pip install uwa-channels`.  MIT license.
- [UnderwaterAcoustics.jl](https://github.com/org-arl/UnderwaterAcoustics.jl): Julia support, maintained by the Acoustic Research Laboratory.  `BasebandReplayChannel` loads a channel (a path, or `uacr://<name>` to download from Zenodo) and `transmit` replays a signal through it; `ReplayNoise` and `PinkGaussianNoise` add the noise models ([pull request #95](https://github.com/org-arl/UnderwaterAcoustics.jl/pull/95), not yet merged).
- [Channel estimation](https://github.com/uwa-channels/estimate): MATLAB/Octave scripts that estimate a channel from a recording, in the file format above, and plot it.
- [Calibration](https://github.com/uwa-channels/calibrations): runs the MATLAB and Python toolboxes side by side on the released files and reports where they agree.
